# Sacred Valley terrain

`sacred-valley.glb` is a real elevation mesh centered on the Sacred Valley near
Urubamba, Cusco, Peru. It was generated from Mapzen Terrain Tiles hosted in the
AWS Open Data Registry, tile `11/613/1100`, accessed September 11, 2026.

SRTM terrain data courtesy of the U.S. Geological Survey.

Source: https://registry.opendata.aws/terrain-tiles/

Attribution details: https://github.com/tilezen/joerd/blob/master/docs/attribution.md
